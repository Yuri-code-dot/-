# καλλιτέχνις

A touch-first web drawing studio for sketching, line art, and reference-based drawing.

> **Eureka** — an experimental drawing space built for the web.

## Vision

καλλιτέχνις is designed around the canvas rather than a traditional desktop toolbar.

- ✍️ Touch-first drawing
- 🖼️ Reference image import for line work
- 🎚️ Reference opacity controls
- 🔒 Lockable reference layers
- 🗂️ Layer-based workflow
- 👆 Long-press tool selection
- ◜ Semi-circular contextual tool menu
- 💾 Local-first saving
- 📤 Image export

## Planned stack

React + TypeScript + Vite + HTML Canvas.

## Status

🚧 Early prototype — building the interaction system first.
